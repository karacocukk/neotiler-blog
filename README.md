# Neotiler Blog Theme

[![Neotiler Blog Preview](tema_screen.png)](https://getneotiler.com)

A modern, highly performant, and customizable WordPress tech blog theme built with Tailwind CSS v4. Created by [getneotiler.com](https://getneotiler.com).

## Features

* **Tailwind CSS v4:** Utility-first CSS framework for rapid UI development.
* **Responsive Design:** Optimized for all screen sizes with CSS Grid and Flexbox.
* **Modern Typography:** Uses Inter and Montserrat fonts for a premium look.
* **Dynamic Category Grids:** Unique layouts for different category sections.
* **Customizer Support:** Easily select featured categories right from the WordPress Customizer.
* **No jQuery:** Vanilla JavaScript for better performance.
* **Developer Friendly:** Ready to be modified and extended.

## Installation

1. Download the latest `neotiler-blog.zip` from the repository releases or clone the repo.
2. Go to your WordPress admin panel: **Appearance -> Themes -> Add New**.
3. Upload the `.zip` file and click **Install Now**.
4. Click **Activate**.

## Development & Customization

If you want to contribute or modify the theme for your own use, you need Node.js installed to compile Tailwind CSS.

### Setup

```sh
npm install
```

### Build Commands

To build for production (compiles Tailwind CSS and prepares `style.css` with WP headers):
```sh
npm run build
```
