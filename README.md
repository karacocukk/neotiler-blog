# Neotiler Blog Theme

![Neotiler Blog Theme Screenshot](./tema_screen.png)

A modern, highly performant, and customizable WordPress tech blog theme built from the ground up with **Tailwind CSS v4**.

## 🚀 About Us: Who is Neotiler?

At **Neotiler**, we believe that the web should be beautiful, fast, and accessible. We are a passionate team dedicated to crafting premium, open-source WordPress themes and tools for modern creators, bloggers, and tech enthusiasts. 

Our mission is to provide pixel-perfect, highly performant, and deeply customizable solutions without the bloat of heavy page builders or legacy code. **Neotiler Blog Theme** is our gift to the open-source community—a lightning-fast, modern tech blog template for everyone.

## ✨ Features We Offer

We designed this theme to be the ultimate starting point for any tech blog, news site, or magazine. Here's what makes it special:

* **Tailwind CSS v4 Engine:** Built natively with the latest utility-first CSS framework for rapid, consistent UI development and tiny bundle sizes.
* **Modern & Airy Aesthetics:** A clean, spacious design that puts your content first. Inspired by top-tier tech publications.
* **Premium Typography:** Ships with carefully selected Google Fonts (**Inter** and **Montserrat**) for maximum readability and a premium feel.
* **Dynamic Category Grids:** Two distinct, dynamic layout modes (Layout A & Layout B) for displaying categories on the homepage. Perfect for mixing news, reviews, and featured stories.
* **WordPress Customizer Integration:** Easily select which categories to feature on your homepage directly from the native WordPress Customizer. No coding required!
* **100% Responsive & Mobile First:** Looks stunning and functions flawlessly on desktops, tablets, and smartphones.
* **Zero jQuery Dependency:** We use Vanilla JavaScript for all interactions, keeping your site blazingly fast and modern.
* **Developer Friendly:** Clean code architecture, well-commented templates, and ready to be modified or extended for your own custom projects.

## 📦 Installation

1. Download the latest `neotiler-blog.zip` from the repository releases or clone the repo.
2. Go to your WordPress admin panel: **Appearance -> Themes -> Add New**.
3. Upload the `.zip` file and click **Install Now**.
4. Click **Activate**.

## 🛠️ Development & Customization

If you want to contribute or modify the theme for your own use, you need Node.js installed to compile Tailwind CSS.

### Setup

```sh
npm install
```

### Build Commands

To build for production (compiles Tailwind CSS and prepares `style.css` with WP headers):
```sh
npm run build
```
